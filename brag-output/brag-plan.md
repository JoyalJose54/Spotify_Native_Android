# Brag Plan: Spotify Native Android

## What is this app?
A flagship native Android music streaming client engineered from scratch with Kotlin, Jetpack Compose, Media3 ExoPlayer, and real-time on-device 4096-point STFT vocal suppression (Karaoke mode).

## The angle
Most streaming clones are just web wrappers or shallow UI skins. Spotify Native Android is a commercial-grade native audio engineering showcase: 120Hz fluid motion UI, GPU orbital fluid mesh gradients, instant zero-reload Room caching, and a real-time digital signal processor that eliminates vocal frequencies on the fly directly inside ExoPlayer's audio graph.

## Key moments (the middle)
- **120Hz Jetpack Compose & Fluid Mesh**: The sleek dark-mode Now Playing screen appears with real-time album artwork palette extraction and an animated fluid orbital gradient backdrop.
- **Real-Time Vocal Suppression (Apple Sing / Karaoke)**: Simulated tap on the "🎙️ Karaoke Mode" toggle. The audio spectrum instantly shifts, isolating center-panned vocals via a 4096-point STFT audio processor with 0ms latency.
- **Zero-Reload Engine & Cloud Pipeline**: 3 instant highlight badges snap into place: "0ms SQLite Room Cache", "256k AAC Pristine Audio", and "Zero Network Latency".

## User flow worth showing
1. **Entry**: Album playback begins in the Now Playing screen with dynamic GPU mesh backdrop and rolling tabular timer.
2. **Key Action**: User toggles "Karaoke Mode" — 4096-point STFT processor activates in real time on the ExoPlayer audio graph.
3. **Result**: Vocals drop out cleanly, background accompaniment stays punchy and clear, with zero audio lag.
